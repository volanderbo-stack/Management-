# Розумний менеджмент

Застосунок для вивчення дисципліни «Менеджмент» (основи менеджменту): 15 тем простими словами, 103 тестових питання з поясненнями, 85 карток і термінів, пробний іспит на 20 питань і сторінка прогресу.

Працює в браузері на телефоні й комп'ютері. Його можна встановити на головний екран як звичайний застосунок, і після першого відкриття він працює без інтернету.

## Що всередині

| Файл | Призначення |
|---|---|
| `index.html` | Увесь застосунок: дані, дизайн і логіка в одному файлі |
| `manifest.webmanifest` | Назва, кольори й іконки для встановлення на телефон |
| `sw.js` | Service worker для офлайн-режиму |
| `icons/` | Іконки застосунку |
| `ОПИС.md` | Докладний опис структури даних і коду |
| `.nojekyll` | Щоб GitHub Pages віддавав файли як є |
| `android-build/` | Налаштування для збірки Android-застосунку (APK) через Capacitor |
| `.github/workflows/` | Автоматична збірка APK і публікація сайту на GitHub Pages |

## Як встановити на телефон

### Android: файл APK (найпростіше)

1. Відкрийте на телефоні сторінку **Releases** репозиторію:
   `https://github.com/volanderbo-stack/Management-/releases/latest`
2. Завантажте файл **Rozumnyi-Menedzhment.apk**.
3. Відкрийте завантажений файл. Якщо телефон попросить, дозвольте «Встановлення з невідомих джерел» для браузера.
4. Іконка «Розумний менеджмент» з'явиться на головному екрані.

APK збирається автоматично (GitHub Actions → **Android APK**) після кожної зміни `index.html`, іконок або `android-build/`. Нова версія ставиться поверх старої, прогрес зберігається.
Запустити збірку вручну: вкладка **Actions** → **Android APK** → **Run workflow**.

### iPhone і Android: через браузер (PWA)

Застосунок доступний за адресою `https://volanderbo-stack.github.io/Management-/`
Сайт публікується з гілки `gh-pages`, яку автоматично оновлює GitHub Actions → **GitHub Pages** після кожної зміни `index.html` чи іконок.

- **Android (Chrome):** відкрийте посилання, меню ⋮ → «Встановити застосунок» або «Додати на головний екран».
- **iPhone (Safari):** відкрийте посилання, «Поділитися» → «На екран „Додому“».

## Прогрес

Результати тестів, прочитані теми й картки зберігаються в браузері (`localStorage`) на цьому пристрої. Між телефоном і ноутбуком вони не синхронізуються.

## Як оновити застосунок

Змініть `index.html`, а потім у `sw.js` збільште номер версії кешу (`rozumnyi-menedzhment-v1` → `v2`). Тоді телефон точно завантажить нову версію. Після пушу сайт і APK оновляться самі.
